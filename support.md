# OneDrive Photos support

The app requires macOS 13 or later and a personal Microsoft account with OneDrive. Sign in with Microsoft, then choose Refresh Now in Settings if the library or albums are not current.

Browsing uses read access. Uploads and album changes request additional Microsoft consent only when you enable those actions. Free Preview Cache removes thumbnails; Free Up Space removes local downloaded originals. Neither deletes OneDrive files.

For a bug or feature request, [open a public issue](https://github.com/MBuelowius/OneDrivePhotos-support/issues/new). Include the macOS version, app version, the visible error, and steps to reproduce with synthetic or non-sensitive data.

Issues are public. Do not post passwords, access tokens, account identifiers, signed URLs, personal media, or private file names. Use Settings → Remove Local Data to remove the signed-in account's app-managed local files. Older builds may retain a shared cache; mention only that you used an older build when requesting cleanup guidance.
