Album Harbor support

Album Harbor requires macOS 13 or later and a personal Microsoft account with OneDrive. Microsoft work and school accounts are not supported by this release. Customers sign in with Microsoft; they do not create an app registration or enter a client secret. The app is independent and is not endorsed by Microsoft or Apple.

Connect and refresh

Choose Sign in with Microsoft, then select your personal account. Browsing requests User.Read and Files.Read. If Microsoft says your session needs attention, sign out and sign in again. Use Refresh to reload the library and cloud albums. Opening cloud originals or refreshing requires internet access; items kept downloaded can be opened offline.

Organize and edit

Browse photos and videos, use cloud albums, or make local smart albums and folders. Favorites, hidden status, captions, keywords, local album arrangement, photo adjustments, and video trims stay on this Mac. Originals in OneDrive are changed only by an explicit cloud operation. Text indexing and duplicate checking can download originals and use extra storage; recognition and file comparison run locally.

Hidden and Recently Deleted views use Touch ID or your Mac password. Their display protection does not encrypt local files. Keep backups of important media; Recently Deleted is not a backup or a complete browser for Microsoft's recycle bin.

Upload, delete, restore, and share

Enable OneDrive changes to upload files, edit cloud albums, create sharing links, or move originals to the recycle bin. Microsoft requests Files.ReadWrite. Restoring a cloud-deleted file requests Files.ReadWrite.All separately. Removing a file from an album keeps the original; moving an original to the recycle bin affects OneDrive and other clients.

Use Transfers to review progress and retry an interrupted supported transfer. Failed uploads retain a staged local copy for retry. Clearing completed or cancelled transfers removes retained cancelled upload copies. A OneDrive sharing link is an anonymous view link; manage or revoke it in OneDrive. Export settings control saved edits and metadata; an unmodified original retains its metadata. The macOS sharing picker sends files to the service you choose.

Manage storage

Keep Downloaded stores originals in app storage. Free Up Space removes downloaded copies without deleting OneDrive content. Turning off Keep whole library downloaded does not remove existing downloads. Free Preview Cache removes thumbnails, which can download again.

Sign Out keeps the local library. While signed in, Remove Local Data deletes the account's local library and text index, local edits and organization, thumbnails, originals, transfer records, staged uploads, and account-specific temporary export and sharing files. Exported files in a folder you chose, content already sent to another service, and cloud files remain. Earlier shared-cache files, unscoped sharing copies, and app-wide preferences may remain. See the privacy policy.

Report a problem

Open a public support issue with the macOS version, app version, the action that failed, and the visible error. Check text and screenshots before posting. Do not include account details, credentials, signed URLs, private file names, recognized text, locations, or personal media. No experimental People feature is included in the store release.
